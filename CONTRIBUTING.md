# Как помочь проекту

Lumen бесплатный и живёт на добровольных донатах, поэтому **самая ценная
помощь — контент, а не код**. Кода в игре немного, и он пишется один раз;
контент нужно делать, вычитывать и поддерживать постоянно.

Порядок ценности вкладов, честно по убыванию:

1. **Вычитка носителем** уже написанного яруса.
2. **Новое созвездие** на A0–A2.
3. **Новый язык подсказок** — он дешевле языка изучения втрое.
4. Код.

---

## Вычитка: самое нужное

Ярус не запускается, пока его не вычитал носитель. Список запущенных ярусов
— в [`content/launch.yaml`](content/launch.yaml); всё остальное написано, но
играть по нему нельзя.

Что проверять:

- **формы и артикли** — по словарю, а не по памяти;
- **фразы**: звучат ли они как живая речь, а не как перевод с русского;
- **дистракторы `near`**: они должны быть *созвучны*, а не просто похожи
  буквами. Валидатор выводит сомнительные пары списком со знаком `?` —
  начните с них;
- **дистракторы `far`**: та же тема, но другое значение. Слово из другого
  конца словаря делает круг угадайкой.

Вычитали ярус целиком — добавьте его в `launched` в `launch.yaml` и впишите
себя в `reviewers`. Это не формальность: по этому файлу приложение решает,
что можно показывать игроку.

## Формат исходников

Всё в `content/`, обычный YAML, править можно текстовым редактором. Полное
описание — [`docs/CONTENT_PIPELINE.md`](docs/CONTENT_PIPELINE.md).

```
content/
  launch.yaml              какие ярусы вычитаны
  constellations/*.yaml    какие концепты на каком ярусе + фразы
  lang/*.yaml              формы, артикли, дистракторы
  calibration/*.yaml       набор для калибровки
```

Созвездие:

```yaml
constellation: doctor
tiers:
  a0:
    concepts:
      - { id: doctor_person, pos: noun, freq_rank: 1120 }
    phrases:
      - id: doctor_a0_help
        template: "Ich brauche {help}."
        answer: Hilfe
        register: casual
        concepts: [help_noun]
```

Лексема:

```yaml
  doctor_person:
    form: Arzt
    article: der
    gender: m
    plural: Ärzte
    distractors:
      far:  [Zahn, Pflege]        # та же тема, другое значение
      near: [Art, Arm, Ast]       # созвучные и однокоренные
```

Два правила, которые ломают сборку, если их нарушить:

- **`id` концепта уникален глобально**, а не внутри созвездия: при смене
  языка изучения прогресс не удаляется, а фильтруется по языку;
- **размеры созвездий накопительные** — 12 / 24 / 48 / 72 / 96 звёзд на
  ярусах A0…B2. Валидатор проверяет это для запущенных ярусов.

## Проверка перед отправкой

```bash
dart run tool/validate_content.dart --lang de
dart run tool/build_content.dart --lang de
flutter test
```

Валидатор различает три уровня и говорит прямо:

- `✗` — ошибка, блокирует мерж;
- `?` — сомнительное на ручную вычитку (обычно `near`-дистрактор, который
  эвристика не признала созвучным);
- `…` — осознанно не сделанное, что придёт с будущей вехой.

Собранный `assets/content/de.db` коммитится вместе с исходниками: сборка
воспроизводима байт-в-байт, поэтому диффа не будет, если контент не менялся.

## Новый язык подсказок

Стоимость линейная, потому что концепты уже есть:

1. `content/lang/<код>.yaml` — формы для существующих концептов. Дистракторы
   для языка подсказок необязательны.
2. Добавьте код в `projectLangs` в `tool/content_schema.dart`.
3. Добавьте локаль в `LanguageScreen`.
4. `validate_content` зелёный.

Озвучка не нужна: подсказки не проговариваются. Это примерно 5 300 строк на
весь курс — выходные работы, а не месяц.

## Код

- Домен (`lib/domain/`) — **чистый Dart**: ни Flutter, ни Drift, ни сети, ни
  `dart:io`. Это то, что позволяет прогонять калибровку на тысяче
  синтетических игроков и измерять её ошибку.
- Числовые константы геймдизайна живут **только** в
  `lib/domain/scoring/balance.dart` и помечены `TODO(balance)`.
- Две базы: `content.db` read-only из ассетов, `user.db` с миграциями. Ни
  одна таблица не живёт в обеих.
- Перед коммитом: `flutter analyze` чисто, `flutter test` зелёные.

Остальные инварианты — в [README](README.md) и [AGENT.md](AGENT.md).
Нарушить их легко, поэтому они вынесены отдельными списками.

## Чего в игру не примут

Список отказов — такая же часть дизайна, как список фич
([docs/CONCEPT.md](docs/CONCEPT.md)). Не примут:

- жизни, сердца, энергию;
- обнуление серии за один пропуск;
- таймер на новом материале;
- рейтинг по XP или любой валюте, которую можно нафармить повтором лёгкого;
- ботов под видом живых соперников;
- обязательный порядок прохождения;
- платные стены, рекламу и валюту за деньги.

Каждый пункт — механика, которая работает на метрики и вредит обучению.
