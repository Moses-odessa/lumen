# Рабочая сборка словника

Идёт подготовка самостоятельной редакторской подборки 6000 немецких лексем A0–B2. Учебный контент приложения не изменяется.

План: сквозные темы, уровень первого введения, артикли существительных, части речи, автоматическая проверка количества и повторов. Открытые материалы Goethe, Hueber и Wikivoyage используются как ориентиры тем и учебных задач, не для копирования их словарей или упражнений.
