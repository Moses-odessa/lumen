# Пайплайн контента

Контент — самая дорогая часть проекта. Кода в игре немного и он пишется один
раз; контент нужно делать, вычитывать и поддерживать постоянно, а денег на это
нет (см. решение о бесплатности в [CONCEPT.md](CONCEPT.md)). Отсюда два правила,
которые задают весь пайплайн:

1. **Сборка полностью воспроизводима из текстовых исходников в репозитории.**
   Никаких «я поправил в базе руками». Воспроизводима буквально: одни и те же
   YAML дают байт-в-байт тот же `content.db`. Поэтому порядок файлов
   фиксирован сортировкой, а в метаданных нет метки времени — вместо неё
   `source_hash` (хеш исходников) и `source_revision` (git).
2. **Язык не запускается, пока его ярусы не вычитаны человеком.** Лучше три
   хороших языка, чем двадцать сгенерированных.

---

## Исходники

Лежат в `content/` в репозитории, по файлу на созвездие:

```
content/
  constellations/
    doctor.yaml
    rent.yaml
    interview.yaml
  calibration/
    de.yaml
  lang/
    de.yaml        # лексемы немецкого для всех концептов
    ru.yaml
    uk.yaml
    en.yaml
```

Пример созвездия — ярусы задают, какие концепты добавляются на каком уровне:

```yaml
constellation: doctor
tiers:
  a0:
    concepts: [doctor_person, pain_verb, help_call, head_body, ...]   # 12
    phrases:
      - id: doctor_a0_help
        template: "Ich brauche {help}."
        answer: Hilfe
        register: casual          # необязательно: 'formal' | 'casual'
        concepts: [help_call]     # какие концепты закрывает фраза
  a1:
    concepts: [appointment_make, fever, prescription_ask, ...]        # +12 → 24
  a2:
    concepts: [pharmacy, sick_note, dosage, ...]                      # +24 → 48
  b1:
    concepts: [insurance_cover, referral, lab_result, ...]            # +24 → 72
  b2:
    concepts: [copayment, appeal_decision, findings_report, ...]      # +24 → 96
```

Концепт задаётся либо строкой-идентификатором (как выше), либо картой, когда
нужно указать часть речи и частотность — короткая форма существует затем,
чтобы файл созвездия читался как список, а не как таблица:

```yaml
    concepts:
      - { id: doctor_person, pos: noun, freq_rank: 1120 }
      - { id: sick_adj, pos: adj, freq_rank: 1450 }
```

`id` концепта уникален **глобально**, а не внутри созвездия: при смене языка
изучения прогресс не удаляется, а фильтруется по языку через `content.db`
(см. [DATA_MODEL.md](DATA_MODEL.md)).

Пример лексем:

```yaml
lang: de
lexemes:
  bill_restaurant:
    form: Rechnung
    article: die
    gender: f
    plural: Rechnungen
    distractors:
      far:  [Ordnung, Gericht]        # тема ресторана, но другое значение
      near: [Rechner, Richtung, Sitzung]   # созвучные и однокоренные
```

## Инструменты

Всё на Dart, в `tool/`, чтобы в проекте был один язык.

| Команда | Что делает |
| --- | --- |
| `dart run tool/build_content.dart --lang de` | собирает `assets/content/de.db` из YAML |
| `dart run tool/validate_content.dart --lang de` | проверки полноты и качества, запускается в CI |
| `tool/content_schema.dart` | не команда: DDL и константы формата, общие для сборщика и валидатора |
| `dart run tool/synthesize_audio.dart --lang de` | TTS с кешем по хешу текста → Opus в `assets/audio/de/` + манифест |
| `dart run tool/make_challenge.dart --lang de --days 30` | JSON ночных вызовов на месяц вперёд |
| `dart run tool/pack_audio.dart …` | **только с M8** — архивы паков для CDN, когда языков станет больше одного |

`build_content.dart` использует пакет `sqlite3` и пишет обычную SQLite-базу —
Drift для этого не нужен, база read-only.

## Проверки валидатора

Запускаются в CI, падение блокирует мерж.

- у каждого концепта есть лексема на каждом языке проекта;
- у каждой лексемы и фразы есть файл аудио — **концепт без озвучки не проходит**,
  потому что звук верного ответа это часть ядра игры;
- у каждого концепта не меньше 2 дистракторов типа `far` и 3 типа `near`;
- дистракторы принадлежат тому же ярусу и не совпадают с ответом ни в одной
  форме;
- `near`-дистракторы действительно созвучны — эвристика по общему началу,
  общему окончанию и расстоянию Левенштейна; всё сомнительное выводится
  списком на ручную проверку, а не молча пропускается. Окончание здесь не
  менее важно, чем начало: в немецком созвучие часто идёт по суффиксу
  (Medikament / Instrument, Krankenhaus / Kaufhaus);
- размеры созвездий соответствуют ярусам (12 / 24 / 48 / 72 / 96);
- нет дублей форм внутри одного созвездия и яруса;
- набор калибровки покрывает все пять ярусов минимум по 30 позиций.

## Сколько это стоит на самом деле

Созвездие «У врача» написано целиком на всех пяти ярусах именно затем, чтобы
цену контента можно было не оценивать, а измерить и умножить на 30
(PLAN.md, M4). Замеры на нём:

| Что | Одно созвездие | ×30 созвездий |
| --- | --- | --- |
| Концептов | 96 | ~2 900 |
| Фраз | 48 | ~1 400 |
| Строк YAML, созвездие | 369 | ~11 000 |
| Строк YAML, немецкий с дистракторами | 753 | ~22 600 |
| Строк YAML, три языка подсказок | 529 | ~15 900 |
| Дистракторов (5 на слово) | 480 | ~14 400 |
| `content.db` | 192 КБ | ~5,8 МБ |

**Что из этого следует.**

- **Объём курса из CONCEPT.md сходится:** 30 созвездий дают ~2 900 концептов,
  а не 5 000. Либо созвездий нужно ближе к 50, либо цель по словарю надо
  честно понизить. Первое дороже ровно в полтора раза, и это решение
  геймдизайна, а не инженерии.
- **Главная статья расходов — дистракторы, а не переводы.** На одно слово
  приходится пять подобранных вариантов, и подобрать их машинально нельзя:
  созвучность живёт в фонетике. Валидатор снимает часть работы, выводя
  сомнительные пары списком (сейчас 18 из 480), но решение остаётся за
  человеком.
- **Языки подсказок дешевле языка изучения втрое:** им не нужны ни
  дистракторы, ни озвучка. Добавление нового родного языка — это ~5 300
  строк на весь курс, то есть выходные работы, а не месяц.
- **Озвучка: 3,99 КБ на позицию — измерено, а не оценено.** 32 позиции двух
  языков в Opus 24 kbps mono весят 128 КБ; в WAV те же данные занимали 82,7 КБ
  на позицию, то есть кодек дал **сжатие в 20,7 раза**. Экстраполяция на весь
  курс (2 900 слов и 1 400 фраз) — около **17 МБ**, лучше бюджета README в
  22 МБ. Без `ffmpeg` синтезатор оставляет WAV, и тот же курс весит 350 МБ,
  поэтому кодек не опция, а требование: `winget install --id Gyan.FFmpeg -e`.

**Чего пока нет.** Набор калибровки: 30 позиций на ярус требуют примерно
трёх созвездий на каждом ярусе, одного не хватает физически. Валидатор
говорит об этом прямо, а не молчит.

## Что считается запущенным

`content/launch.yaml` перечисляет ярусы, вычитанные человеком. Это машинная
форма правила «язык не запускается, пока его ярусы не вычитаны»:

- **валидатор** требует полноты — размеров созвездий, озвучки, набора
  калибровки — только от запущенных ярусов, остальные помечает как `…`;
- **синтезатор** озвучивает только запущенные: класть в репозиторий
  мегабайты, которые придётся пересинтезировать после первой правки, незачем;
- **приложение** не даёт ни выбрать, ни получить в предложении ярус выше
  запущенного: список едет в `content_meta.launched_tiers` и читается в
  рантайме.

Ярус попадает в `launched` только после сплошной вычитки. Лучше три хороших
яруса, чем двадцать сгенерированных.

## Источники данных

- **Частотность:** частотные списки по субтитрам и корпусам — определяют
  `freq_rank` и попадание концепта в ярус. Первые 5 000 концептов покрывают
  примерно 90 % бытовой речи.
- **Уровни CEFR:** официальные профили — Goethe/ÖSD для немецкого, English
  Vocabulary Profile для английского. Помечать `TODO(data)` со ссылкой.
- **Примеры и фразы:** генерация LLM по строгому шаблону, затем вычитка.
  Сплошная на A0–A2, выборочная (5 %) выше — но выше и запускать не стоит, пока
  нет носителя-редактора.
- **Аудио:** TTS на старте, записи носителей по мере роста. Формат Opus 24 kbps
  mono — это 3 КБ на секунду звука, то есть около 2–3 КБ на слово и 7–8 КБ на
  фразу.

## Доставка аудио

**Всё в ассетах, все ярусы сразу.** Никакой докачки, никакого сетевого клиента,
никакого кеша.

Арифметика позволяет: один язык изучения это ~5 000 слов и ~1 500 фраз, то есть
примерно 13 МБ + 11 МБ ≈ **25 МБ** в Opus 24 kbps mono. Вместе с базой Flutter и
контентной БД APK укладывается в 45–55 МБ — нормальный размер для игры.

Это осознанно отложенная сложность, а не недоделка. Загрузчик паков тянет за
собой прогресс, возобновление, проверку хешей, инвалидацию кеша, управление
местом в настройках и ветки «нет сети» в самых неудачных местах — и всё это
ради экономии двадцати мегабайт на этапе, где важнее быстро проверять идеи.

**Когда это изменится.** Ровно на M8, по одному из двух триггеров:

1. появляется **второй язык изучения** — два языка в ассетах это уже под сотню
   мегабайт, и дальше линейно хуже;
2. TTS заменяется на **записи носителей** — качество выше, битрейт выше, вес
   растёт кратно.

До наступления любого из них файл `tool/pack_audio.dart` не пишется, а `http` и
`archive` не появляются в `pubspec.yaml`. Когда наступит — паки публикуются в
GitHub Releases (бесплатно, надолго хватает), при росте переезжают на
Cloudflare R2 с нулевым egress; обе опции совместимы с моделью «расходы близки
к нулю».

## Добавление нового языка

Стоимость линейная, потому что концепты уже есть:

1. `content/lang/<code>.yaml` — формы, артикли, дистракторы для существующих
   концептов.
2. `dart run tool/synthesize_audio.dart --lang <code>`.
3. Вычитка носителем ярусов A0–A2.
4. `validate_content` зелёный → язык появляется в списке.

Добавление второго языка **изучения** дополнительно требует M8 — озвучка двух
языков в ассетах уже не помещается. Добавление нового **родного** языка (языка
подсказок) аудио не требует вовсе и остаётся дешёвым.

Пары собираются на лету: любой язык из набора может быть родным для любого
другого. Это даёт направления вроде «украинский → немецкий», которых у крупных
приложений просто нет.
