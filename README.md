# Lumen (`lumen`)

Игра для изучения языков — **разговорник**: единица изучения это фраза, а не
слово. Разговорник — ночное небо: фразы это звёзды, темы — созвездия, а яркость
звезды в **люменах (lm)** равна вероятности вспомнить фразу прямо сейчас.

Механика одна на три вида: в центре экрана фраза или звук, вокруг **шесть**
вариантов, нужно соединить с нужным. На ответ пять секунд, после которых
верный вариант подсвечивается и произносится сам — просрочка считается «не
вспомнил». Новая фраза даётся среди пяти уже известных: игрок понимает, какая
шестая, потому что остальные узнаёт, — и на знакомстве окна на ответ нет,
торопить тут нечего.

Приложение **полностью бесплатное**, без рекламы и подписок, живёт на
добровольных донатах. Отсюда главное инженерное требование: стоимость одного
пользователя в месяц стремится к нулю, то есть **offline-first без обязательного
сервера**.

## Быстрый старт

```bash
flutter pub get
dart run build_runner build                  # Drift
flutter gen-l10n                             # ARB → Dart
dart run tool/build_content.dart --lang de   # сборка assets/content/de.db
flutter run
```

`build_runner` начиная с 2.15 удаляет конфликтующие выводы сам — флаг
`--delete-conflicting-outputs` больше не нужен и игнорируется.

Идентификатор приложения — `odessa.moses.lumen`.

Единственный ключ — DSN мониторинга, и он необязателен:

```bash
flutter run --dart-define=SENTRY_DSN=...
```

## Технологии

Стек сознательно повторяет `athlete_index` — тот же канал Flutter, те же
библиотеки состояния, навигации, БД и CI. Это экономит время на настройке и
позволяет переносить решения между проектами.

| Слой | Технология |
| --- | --- |
| Платформа | Flutter (канал **beta**, 3.47.x / Dart 3.13.x), Android + iOS |
| Состояние | `flutter_riverpod` (Notifier/NotifierProvider, производные Provider) |
| Навигация | `go_router` (`StatefulShellRoute.indexedStack` для 4 вкладок, redirect-гейты) |
| Локальная БД | `drift` + `drift_flutter` (SQLite), кодоген `drift_dev`/`build_runner` |
| Контентная БД | предсобранная read-only SQLite в ассетах, открывается отдельным `NativeDatabase` |
| Звук | `flutter_tts` — синтез речи устройства, без записанных файлов |
| Аудио | не поставляется: голос берётся у системы, отсутствие голоса проверяется до игры |
| Отрисовка неба | `CustomPainter` + `GestureDetector` (карта созвездий, круг, анимации) |
| Бэкенд | нет: приложение полностью локальное |
| Уведомления | `flutter_local_notifications` (ежедневное напоминание) |
| Мониторинг | `sentry_flutter` (краши; PII выключен, трейсинг 0) |
| Аналитика | собственный фасад `AnalyticsService` (логирующая реализация по умолчанию) |
| Локализация | `flutter_localizations` + gen-l10n (ARB), `LocalizedText` для доменного контента |
| Прочее | `path_provider`, `share_plus`, `url_launcher`, `flutter_launcher_icons`, `flutter_native_splash`, `crypto` |
| Тесты | `flutter_test`, `mocktail` |
| Инструменты сборки контента | Dart CLI в `tool/`, пакеты `sqlite3`, `yaml`, `csv`, `crypto` |

### Что берём из athlete без изменений

`flutter_riverpod`, `go_router`, `drift`/`drift_flutter`, `sentry_flutter`,
`flutter_local_notifications`, `path_provider`, `url_launcher`,
`flutter_launcher_icons`, `flutter_lints`, `mocktail`, `build_runner`,
`drift_dev`, `flutter_localizations` + gen-l10n.

### Что добавляем

`flutter_tts` (озвучка верного ответа — часть ядра игры, и она делается
синтезом устройства, а не записанными файлами) и dev-зависимости для
инструментов: `sqlite3`, `yaml`, `csv`, `crypto` для сборки контентной БД.
Последние не попадают в приложение — только в `tool/` и в тесты, которые
сверяют DDL сборщика со схемой Drift.

`win32` нужен потому, что системный синтезатор Windows (SAPI) — это
COM-интерфейс. Вызывать его из Dart напрямую вышло дешевле, чем через
`powershell.exe`: там поднимался процесс на каждое слово, и антивирусы
считали это доставкой вредоносного кода — блокировали, не разбирая.

**Сетевого клиента в проекте нет вообще.** Ни `http`, ни `archive`, ни
`supabase_flutter`: облако, докачка аудио-паков и ночной вызов были написаны
на M6 и M8 и удалены — они требовали хостинга и ключей, а игра обходится без
того и другого. Код лежит в истории git и возвращается одним `revert`, когда
для него появится настоящая причина.

### Что не берём

`fl_chart` — графиков в MVP нет, экран статистики яркости появится не раньше M5
и, возможно, обойдётся своим `CustomPainter`. `pdf` и `reactive_forms` — не нужны:
отчётов нет, форм в игре почти нет.

## Инварианты

Нарушить легко, поэтому вынесено отдельно.

- **`domain/srs`, `domain/scoring`, `domain/calibration`, `domain/scheduler` —
  чистый Dart.** Никаких зависимостей от Flutter, Drift, сети и `dart:io`. Это
  позволяет покрывать их быстрыми юнит-тестами; CI-гейт покрытия `domain/srs` и
  `domain/scoring` ≥ 90 %.
- **Две базы данных, не одна.** `content.db` — read-only, поставляется собранной,
  никогда не мигрируется на устройстве, заменяется целиком при обновлении.
  `user.db` — Drift с миграциями, только пользовательское состояние. Ни одна
  таблица не живёт в обеих. У `ContentDatabase` нет ни одного метода записи,
  а её `MigrationStrategy` намеренно падает: если Drift решил, что нужна
  миграция, значит в ассеты попала база не той версии — это ошибка сборки.
- **DDL сборщика и схема Drift обязаны совпадать.** `tool/build_content.dart`
  пишет `content.db` голым SQL, приложение читает её через Drift; разъехались
  имена колонок — приложение упадёт на первом запросе уже у игрока. Шов
  закрыт тестом `test/data/content_schema_test.dart`, который поднимает базу
  из DDL инструмента и выполняет по ней настоящие запросы Drift.
- **Сборка контента воспроизводима байт-в-байт.** В метаданных нет метки
  времени: вместо неё `source_hash` и `source_revision`. Иначе каждая
  пересборка давала бы новый файл в git на пустом месте.
- **Яркость (lm) не хранится как источник правды.** Источник — тройка FSRS
  `(difficulty, stability, lastReview)`. `lm` вычисляется на лету и кешируется в
  колонке только для быстрой сортировки; при расхождении верна тройка.
- **Скоростной множитель применяется только к фразам с яркостью ≥ 40 lm.**
  На новом материале таймера нет вообще. Это правило геймдизайна, а не UI: оно
  живёт в `domain/scoring` и покрыто тестами.
- **Каждое верное соединение озвучивается.** Звук не блокирует переход к
  следующему кругу: он играет поверх анимации разворачивания, но начатую фразу
  договаривает — следующий круг не обрывает её на середине. Озвучка это синтез
  устройства, файлов звука в проекте нет; поэтому валидатор её и не проверяет,
  а `SpeechService` честно отвечает «голоса нет» и заменяет звук вибрацией.
- **Персистентность — write-through.** Изменения контроллеров пишутся в Drift
  сразу, загрузка выполняется до первого кадра (`bootstrapPersistence`), чтобы не
  мигал онбординг.
- **Новые пользовательские данные добавляются во все три места:** Drift-схема
  (+ миграция), `bootstrapPersistence` (загрузка + write-through) и облачный
  снимок (`encodeUserData` / `decodeUserData` / `mergeUserData`) — последнее с M6.
- **Любой новый контент — сразу `LocalizedText` на все языки интерфейса;**
  строки UI — во все ARB-файлы.
- Числовые константы геймдизайна (пороги lm, множители, длины сессий) помечаются
  `TODO(balance)` и меняются в одном месте — `domain/scoring/balance.dart`.
  Данные контента — `TODO(data)` со ссылкой на источник.

## Контент и мультиязычность

Мультиязычность стоит O(N), а не O(N²), потому что хранятся не пары переводов,
а фраза и её переводы:

```
Phrase { id, lang, tier, constellation, idx, text, kind, register }
  ↳ PhraseTranslation { lang, text }              # перевод на родной язык
Language { code, role, status, name, phrases }     # язык объявляет о себе сам
ConstellationName { constellation, lang, name }    # подпись темы на карте
```

Схема контента v7. До v5 единицей была словарная запись, и рядом с фразой
жили `concepts`, `lexemes`, `distractors`, `phrase_slots`, `phrase_orders`,
`phrase_concepts` — шесть таблиц, обслуживавших слово и вставку слов в
предложение. Разговорнику они не нужны: фраза сама себе запись, а неверные
варианты не пишутся руками — вокруг стоят другие фразы, которые игрок уже
знает.

**v6 добавила имена созвездий** — 250 рядов, пятьдесят тем на пяти языках. До
неё у темы было только имя-slug, и им же она подписывалась на карте:
`first_contact` латиницей посреди немецких фраз. Слаг остался личностью темы
(по нему лежит память игрока и считается раскладка неба, менять его нельзя),
а имя стало подписью — оно приходит из контента и переводится так же, как
фраза. Правило показа одно: **язык интерфейса → язык подсказок → slug**.

**v7 добавила `phrases.kind`** — чем фраза является: готовой репликой
(`phrase`), образцом речевой модели (`example`) или идиомой (`idiom`). В
нынешнем корпусе это 1231 / 239 / 30, и число печатает валидатор при каждом
прогоне, чтобы его не пришлось вписывать сюда и потом сверять глазами.
Колонка нужна **вычитке, а не игре**: круг собирается одинаково из всех трёх.
У идиомы перевод смысловой («Ich habe den Faden verloren.» → «Я потерял нить
мысли.»), и проверяющий без пометки объявит все тридцать переводов неточными;
`example` — законченный образец модели, пришедший на место шаблона с
многоточием («Ich heiße Alex.» вместо «Ich heiße ...»), то есть строка, в
которой имя и число взяты для примера и править их незачем. Отличить эти виды
по тексту нечем, поэтому различие живёт колонкой, а не догадкой, и входит в
отпечаток вычитки яруса (`tierHash`): смена вида меняет то, что читает
проверяющий.

**Язык добавляется одним файлом.** Языки находятся перебором каталога
`content/lang/`, а не списком в коде: файл объявляет свою роль
(`native`/`target`/`both`), готовность (`draft`/`launched`) и самоназвание, и
приносит имена тем и переводы фраз. Список языков в Dart больше не
существует — раньше он лежал в четырёх местах, и добавление языка означало не
забыть ни одного.

Покрытие **считается, а не объявляется**: фраза играбельна в паре
«изучаемый + родной» тогда и только тогда, когда у неё есть перевод. Неполный
язык поэтому даёт меньше фраз, а не чужие: прежняя подстановка английского
вместо отсутствующего перевода убрана намеренно.

**Размер созвездия берётся из контента.** Прежнее правило — ровно
12/24/48/72/96 звёзд накопительно — заменено порогом появления: созвездие
выходит на карту того яруса, на котором у него набралось не меньше восьми
звёзд. При подъёме ярусом выше старые звёзды остаются и продолжают участвовать
в повторениях.

**Черновое не отгружается.** Пометка `draft: true` означает «написано, но не
вычитано», и уважать её обязана сборка, а не только валидатор. До импорта
словника пометку уважал один валидатор — черновиков было ноль, и то, что
сборка их отгружает, проверить было нечем. Сегодня в исходниках фраз черновых
нет ни одной; если появятся, фильтр в сборке надо вернуть.

Отпечаток вычитки яруса (`content_hash` в `content/launch.yaml`) считается по
тому, что видит вычитывающий: тексты фраз яруса, их вид и пометку регистра, их
переводы на все языки. Правка любого из этого делает вычитку устаревшей, и это
видно машинно, а не на глаз. Замена корпуса поэтому отпечатки не «сохранила» —
она их сдвинула, и валидатор говорит, какой отпечаток надо прочитать.

**Вставки слов в предложение больше нет, и это стоит знать целиком.** Сначала
у фразы был один пропуск и шесть слов вокруг, из которых пять посторонние, — и
шесть раундов вычитки ушло на эти списки. Каждый раунд находил в них слово,
дающее правильное немецкое предложение: в рамку, куда влезает одно слово,
влезает и второе. «Ich habe Durst», «Gehen Sie nach links», «Das ist zu spät,
ich kaufe es nicht» — правильный немецкий, объявленный игрой неверным.

Тогда посторонние убрали вовсе: вокруг стали лежать ровно вынутые из
предложения слова, от двух до всех, и вопрос стал про **порядок**. Класс
дефектов ушёл, но пришёл новый: собранный из своих же слов законный другой
порядок — тоже не ошибка игрока, и его пришлось объявлять в контенте
(`orders:`), а вместе с этим появились правило о знаках препинания на плитках
и кнопка «Готово».

Разговорнику ничего из этого не нужно: фраза заучивается целиком, и
спрашивается она тем же кругом, что и всё остальное.

**Вычитка — два независимых прохода разными моделями, и это сказано игроку.**
Носителя нет; экран «О приложении» пишет об этом прямо, вместе с
ограничением: две модели ошибаются согласованно, и от этого страхует не
второй агент, а положительный список слов, составленный не нами. Такого
списка для немецкого пока нет — существование 9288 форм не проверено ничем,
кроме чтения. Работает только отрицательный список: найденная выдумка не
вернётся в контент никогда.

**Но сказано это в прошедшем времени, а сделано не было.** `aboutReviewBody`
обещает игроку, что фразы «перекрёстно проверены второй моделью», а
`content/launch.yaml` держит `passes: []` у всех пяти ярусов. Правило проекта
эту строку не нарушает — нарушает её факт: обещание о качестве учебного
материала, данное человеку, который по нему учится. Открытый вопрос назван в
[PLAN.md](PLAN.md), «Что решить».

Что двойная вычитка A0 нашла, стоит прочитать целиком в [PLAN.md](PLAN.md):
слова прошли все восемь раундов, а фразы каждый раз проваливались на
устройстве механики. Это и стало одним из доводов сменить единицу изучения:
дефект жил не в текстах, а в том, что от текстов требовала механика.

Подробности сборки, источников и валидации — [`docs/CONTENT_PIPELINE.md`](docs/CONTENT_PIPELINE.md).

## Локализация интерфейса

Те же шесть языков, что в `athlete_index`: английский (шаблон), русский,
украинский, немецкий, итальянский, французский. ARB в `lib/core/l10n/arb/`,
конфиг — `l10n.yaml`, генерация — `flutter gen-l10n`.

Родной язык игрока (язык подсказок в игре) и язык интерфейса — **разные
настройки**: человек может учить немецкий с украинского, а интерфейс держать на
английском.

**Имён созвездий в ARB нет, и это не пропуск.** Имя темы — контент: тема
приезжает вместе с фразами, и её подпись обязана добавляться тем же одним
файлом в `content/lang/`, а не правкой кода. Технически в ARB ей места и нет —
`gen-l10n` не достаёт строку по вычисляемому ключу (slug из базы), и пятьдесят
тем стали бы `switch` на пятьдесят ветвей. Локалей интерфейса при этом шесть, а
языков контента пять: французского контента нет вовсе, поэтому подпись темы
идёт по откату **язык интерфейса → язык подсказок → slug**
(`lib/data/content/constellation_naming.dart`). Язык интерфейса решается
**один раз** — `interfaceLangProvider` в `lib/core/l10n/interface_lang.dart`
вызывает ту же `basicLocaleListResolution`, которой его решает Flutter, и
`MaterialApp` получает локаль оттуда же: два независимых ответа на «какой язык
у интерфейса» разошлись бы на локали вне `supportedLocales`.

Полнота локализации проверяется тестом `test/l10n_test.dart`, а не вниманием:
недостающий ключ откатывается к английскому молча, и англоязычный
разработчик такого не замечает никогда. Тест сверяет состав ключей,
плейсхолдеры и то, что локаль вообще переводили.

**TODO(data): итальянский и французский не вычитаны носителями.** Строки
интерфейса короткие и риск ниже, чем в учебном контенте, но перед публикацией
в сторах их стоит проверить — как и ярусы контента.

Инструменты разработчика — замер задержки звука и диагностика баз — не
локализованы намеренно: они показываются только в debug-сборке.

## Офлайн и приватность

- **Приложение локальное целиком.** Ни одного сетевого вызова, обязательного
  или необязательного: контент в ассетах, прогресс в Drift, озвучка —
  синтезом самого устройства. Аккаунта нет, сервера нет, стоимость одного
  игрока — ровно ноль.
- **Аудиофайлов в установке нет.** Записанная озвучка была и убрана: по
  измеренной цене AAC-LC (5,66 КБ на позицию) она стоила 24 МБ на язык,
  119 МБ на пять, плюс прогон синтеза на каждую правку текста. Синтез
  устройства делает то же бесплатно и говорит новым контентом сразу.
  Цена решения названа: голос принадлежит системе — его нельзя вычитать, он
  разный на разных телефонах, и его может не оказаться. Последнее
  проверяется до начала игры, и игроку предлагают либо поставить голос, либо
  играть без звука.
- **Очки устроены как в аркаде, но без провала.** Заход — цепочка уровней
  подряд: каждый следующий чуть сложнее (больше вариантов в круге, сжатый
  порог автоматизма, выше доля продуктивных механик, длиннее забег) и
  заметно дороже — множитель растёт на четверть за уровень до потолка ×3.
  Награда обгоняет сложность нарочно: иначе оптимальной игрой стало бы
  топтание на первом уровне.

  Провала в жанровом смысле нет — правило «ошибка стоит очков, но никогда не
  блокирует» сильнее жанра. Слабый уровень сбрасывает множитель на первый:
  игрок перестаёт зарабатывать эскалацию, но не теряет накопленного.
  Полчаса без игры закрывают заход, и он начинается заново — иначе «один
  присест» растянулся бы на сутки, а рекорд часа перестал бы что-либо
  означать.
- **Стена рекордов личная, потому что облака нет.** Соперник — ты
  вчерашний: лучший заход, лучший час, день, неделя, месяц. Окна разной
  длины нарочно, и у каждого рядом показано текущее значение: месячный
  рекорд к концу месяца недостижим, а часовой можно побить сегодня же —
  всегда должна быть цель, до которой рукой подать. Текущее окно в рекорд
  не идёт, пока не закрылось, иначе рекорд побивался бы сам собой на
  каждом круге.
- **Резервной копии нет, и это осознанно.** Переустановил — прошёл
  калибровку заново: она попадает в нужный ярус за пару минут и в 99,8 %
  случаев. Облако давало удобство переноса, а не сохранность, и стоило
  ключей, схемы и чужого сервера. Появится настоящий спрос — вернётся из
  истории git вместе с экспортом данных, одним форматом.
- **Приватность:** Sentry с `sendDefaultPii = false` и `tracesSampleRate = 0`
  и только при заданном DSN; полное удаление данных в настройках; никакой
  рекламы и трекеров. Больше приложению просто некуда что-либо отправить.

## Тесты и качество

```bash
flutter analyze          # должно быть чисто
flutter test             # домен + данные + смоук
flutter test --coverage  # + гейт покрытия srs и scoring в CI
dart run tool/validate_content.dart --lang de   # контент: полнота, переводы, вычитка
```

Валидатор различает три уровня: `✗` — ошибка, блокирует CI; `?` — сомнительное
на ручную вычитку; `…` — осознанно не сделанное, что приходит с будущей вехой.

Обязательно покрыто юнит-тестами: FSRS (стабильность, сложность, интервалы,
границы), пересчёт яркости, отображение времени отклика в оценку, множители
очков и комбо, сброс комбо на быстрой ошибке, калибровка (квота проб, вывод
яруса и засев — на тысяче синтетических «игроков»), подбор пула сессии,
расчёт орбиты при пропусках.

**Числа корпуса в тестах считаются, а не вписываются.** Корпус сменился дважды
за короткое время, и вписанная в тест тысяча зеленела бы на полутора: проверки
читают состав из отгруженного ассета. Где это ещё не так — названо в
[PLAN.md](PLAN.md), «Что решить»: там перечислены проверки, которые проходят
впустую.

## CI/CD и сборка

GitHub Actions, канал beta, экшены на рантайме Node 24 (`checkout@v5`,
`setup-java@v5`, `upload-artifact@v7`).

| Workflow | Запуск | Что делает |
| --- | --- | --- |
| `ci.yml` | push / PR | кодоген → `analyze` → валидация контента → сборка `content.db` → `test --coverage` → гейт покрытия `domain/srs` и `domain/scoring` ≥ 90 % → сборка web |
| `content.yml` | вручную | валидация и сборка `content.db`, коммит собранного ассета |
| `test-apk.yml` | вручную | release-APK с debug-подписью для установки на телефон |
| `release-apk.yml` | вручную | подписанный APK по секретам keystore |
| `build-ios.yml` | вручную (macOS) | неподписанная iOS-сборка — проверка компиляции |

Гейт покрытия включается сам, как только появятся `domain/srs` и
`domain/scoring` (M1): пока в lcov по ним нет ни одной строки, шаг честно
пишет `SKIP`, а не показывает зелёное 0 %.

**Секреты репозитория:** `SENTRY_DSN`; для подписанного APK —
`ANDROID_KEYSTORE_BASE64`, `ANDROID_STORE_PASSWORD`, `ANDROID_KEY_PASSWORD`,
`ANDROID_KEY_ALIAS`.

**Ссылки, задаваемые при сборке:** `DONATE_URL`, `EXPENSES_URL`, `SOURCE_URL`.
Пустые значения не ломают приложение — кнопки просто не показываются.

Релизная подпись берётся из `android/key.properties`, которого в репозитории
нет: его создаёт `release-apk.yml` из секретов. Без файла сборка не падает, а
подписывается debug-ключом — так `flutter run --release` и `test-apk.yml`
продолжают работать.

## Состояние проекта

**Вехи M0–M8 закрыты** — их запись в [docs/PLAN_M0_M8.md](docs/PLAN_M0_M8.md).
Работает: круг, забег, уровень, FSRS-5, очки, аркадные заходы и личная стена
рекордов; карта неба с пятьюдесятью созвездиями на пяти ярусах; онбординг с
калибровкой; дневной ритуал, орбита и пуши; звук — синтез устройства с
честной проверкой наличия голоса. Всё локально: ни одного сетевого вызова,
аккаунта нет.

**Закрыты M9, M10, M11 и M14** (см. [PLAN.md](PLAN.md)). Схема контента **v7**,
`user.db` **v7**. Язык добавляется одним файлом в `content/lang/`: списка языков
в коде больше нет.

**Игра стала разговорником.** Единица изучения — фраза; отдельного слова в
игре нет вовсе, и вместе с ним нет лексем, дистракторов, родов, множественных
чисел, словаря игрока и вставки слов в предложение. Механик три:

* фраза на изучаемом → шесть переводов вокруг;
* фраза на родном → шесть фраз на изучаемом;
* фраза звучит сама → шесть переводов вокруг.

Вариантов всегда шесть, и это не настройка: на полном круге держится
знакомство. Новая фраза даётся среди **пяти уже известных** — игрок приходит к
ответу исключением, а не подсказкой. На ответ пять секунд, после которых
верный вариант подсвечивается и произносится; просрочка считается «не
вспомнил». На знакомстве окна нет: читать пять знакомых строчек за пять секунд
— это требование угадать, а не сообразить.

Вопрос на слух в игре один, и варианты у него **на родном языке**. Вторая
механика на слух была («различить похожие», варианты на изучаемом) и удалена:
она проверяла слух отдельно от смысла — игрок выбирал похоже звучащую
строчку, ничего не понимая.

**Круг нарисован под фразу, а не под слово.** Вариант — капсула, размер
которой считается от самой строки; шесть углов прежней окружности сложились в
четыре полосы с центром между ними, а кольцо проходит через центры капсул.
Метафора цела (центр и шесть вокруг), но в кружок фраза не помещалась ни при
каком радиусе, и ниже примерно 400 точек высоты нижний вариант вообще не
нажимался: `Stack` клипует, и hit-test за границу не проходит.

**Варианты выбираются по совпадению слов с ответом** — решение владельца.
Круг из шести непохожих фраз решается по одной случайной примете; когда вокруг
стоят пройденные фразы из тех же слов, отличить их можно только прочитав
целиком. Считается совпадение на языке показа: путается игрок там, где читает.
Полосы памяти сохранены — известные, потом виденные, потом остальные, — потому
что знакомство исключением требует известных, а правило владельца — пройденных.
Насколько правило работает **на первом уровне**, измерено, и ответ там
неприятный: см. [PLAN.md](PLAN.md), «Что решить».

**Двух верных ответов в круге не бывает, и проверка стоит на языке центра.**
Прежняя сравнивала тексты на языке вариантов, а двусмысленность создаёт язык
центра — и пропускала ровно те круги, которые обязана была ловить. В нынешнем
корпусе многоточий и дублей перевода нет ни в одном из пяти языков, поэтому
проверка работает **ограждением**, а не лечением, и в докстроке это сказано
прямо: снять её как «защиту от несуществующего» значит вернуть круг, где игрок
нажимает верное и получает «неверно». Форма с многоточием законна и
возвращается одной правкой листа, а пару одинаковых переводов даст первая же
добавленная тема.

Онбординг — **двадцать кругов с квотой по ярусам**: 6 проб на A0, 5 на A1, 4 на
A2, 3 на B1, 2 на B2. Это стратифицированная выборка, а не поиск: вопрос «куда
шагнуть дальше по результату» не задаётся ни разу, ярус выводится из того, как
игрок отвечал. Заканчивается тест разбором: сколько было кругов, сколько игрок
узнал, что показал тест — и почему выдан другой ярус, если выдан другой.
Причина обычно одна: играть можно только по вычитанному, а вычитан пока A0.

Контент: **1500 фраз в пятидесяти созвездиях**, по тридцать в каждом, из них
150 на запущенном A0 (270 / 330 / 360 / 390 на A1 / A2 / B1 / B2). Языков
подсказок четыре — украинский, русский, английский и итальянский, — и у всех
переводы на все 1500 фраз: корпус пришёл одним источником сразу на пяти языках.
По ярусам созвездия лежат неровно (5, 9, 11, 12, 13): чем выше уровень, тем
больше в нём областей речи.

У каждой темы есть имя на всех пяти языках — 250 рядов `constellation_names`, —
и на карте она подписана именем, а не латинским слагом, как было до схемы v6.

Тридцать фраз на тему перекрывают порог появления созвездия (восемь звёзд), и
это снимает то, чем прежний корпус был непригоден: 432 целых предложения
писались для механики вставки слов, давали по четыре фразы на созвездие на A0
и на карту не выводили **ни одного**.

**Многоточий в корпусе больше нет.** Их было 239 — «Ich heiße ...», «Ich bin
... Jahre alt.» — то есть почти четверть прежней тысячи, и игрок читал место
для своего слова, не понимая, что от него хотят. Владелец заменил такие строки
законченными образцами и заодно расширил лист с 1000 до 1500; вид `example` —
след этой замены. Ценой стала длина: немецкая фраза доросла до 118 знаков
(было 90), итальянский перевод до 112, украинский до 97. Раскладка круга это
держит (проверено нажатием по каждому из шести на пяти размерах экрана, включая
320×480 и ландшафт), а **окно ответа под новую длину не пересчитано** — см.
[PLAN.md](PLAN.md).

**Замена корпуса стоила памяти игрока, и цена названа.** Идентификатор фразы —
`<slug>_<ярус>_<nn>`, где `nn` это позиция в теме, то есть идентификатор
говорит, **где** фраза лежит, а не **что** в ней написано. 761 фраза сохранила
и текст, и позицию, а 239 идентификаторов несут теперь другой текст (235 —
хвост темы на позициях 13–20, четыре — бывшие многоточия в `about_me`). Чистка
памяти сверяет идентификаторы, а не тексты, поэтому такое не ловит и ловить не
может: на устройстве с прогрессом эти записи стали записями о другой фразе.
Подробности и почему дешёвого способа не платить нет — в шапке
`tool/import_phrasebook.dart`.

**Корпус не вычитан, и это известно.** 1500 фраз пришли готовыми и не
читались в этом проекте ни одной моделью. Правило «ярус не запускается, пока
не вычитан двумя проходами по нынешнему тексту» не исполнено, `passes` пусты у
всех пяти ярусов, и валидатор говорит об этом отдельной строкой с отпечатком.
Это единственное, что отделяет «играбельно» от «готово к сторам» — план в
[PLAN.md](PLAN.md).

Реестр лемм (6299 записей) и прежние немецкие лексемы уехали в
`content/_material/`: они больше не материал для написания фраз, а история
словарного слоя. Пайплайн их не читает.

Из M12 уже сделано то, что оказалось починкой существующих ошибок: Млечный
Путь, шкала A0→B2 и время в статистике. Созвездия перекрывались на 41 % с
первого дня, а тест на это проверял, что расстояние между центрами больше
нуля.

Уровень идёт этапами: знакомство (новое среди пяти известных) → закрепление →
проверка воспроизведением → напоминание. Спринт на время
появляется на пройденной теме.

Чего сознательно нет: словарной проверки немецкого (M13 — нужен внешний список
слов, составленный не нами) и словарного слоя вообще. M15 и M16 сняты вместе со
словом, реестр лемм на 6299 записей лежит материалом в `content/_material/`.

Что открыто и с числами — [PLAN.md](PLAN.md), «Что решить»: вычитка 1500 фраз,
окно ответа против выросшей длины фразы, правило совпадения слов на первом
уровне и обещание вычитки на экране «О приложении».
