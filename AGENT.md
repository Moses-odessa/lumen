## Договорённости по работе

- **README обновляется после каждого этапа работ** (новая функция, миграция БД,
  новая зависимость, изменение формата контента, новый язык).
- Перед коммитом: `flutter analyze` — чисто, `flutter test` — зелёные,
  `dart run tool/validate_content.dart` — без ошибок, если трогали контент.
- Кодоген после правок схемы Drift: `dart run build_runner build`
  (флаг `--delete-conflicting-outputs` удалён в build_runner 2.15 и
  игнорируется); после правок ARB: `flutter gen-l10n`.
- После правок `content/*.yaml`: `dart run tool/build_content.dart --lang de`
  и коммит пересобранного `assets/content/de.db` вместе с исходниками.
- Набор калибровки не пишется руками: `dart run tool/make_calibration.dart
  --lang de` пересобирает `content/calibration/de.yaml` по правилу отбора
  (частотность, круг по созвездиям, четыре фразы из тридцати). После
  генерации файл можно править руками — генератор даёт отправную точку.
- Созвучность дистракторов проверяется в звуковой записи
  (`tool/phonetics.dart`), а не в написании: по-немецки рифма сплошь и рядом
  пишется иначе (`Tour` / `Uhr`, `Fleiß` / `Preis`). Список «на ручную
  проверку» держится около 9 % — если он раздуется, чинить надо эвристику, а
  не мириться: длинный список никто не читает.
- Звук — **синтез речи устройства** (`flutter_tts`), а не записанные
  файлы. Записанную озвучку убрали намеренно: она стоила прогона
  синтеза на каждую правку контента и не давала звука новому ярусу до
  этого прогона. Возвращать её нельзя без обсуждения — вместе с ней
  вернётся весь пайплайн: ffmpeg, SAPI через COM, манифесты, проверка
  покрытия и мегабайты в установке.
- Цена перехода названа и принята: голос принадлежит устройству. Его
  нельзя вычитать, он разный на разных телефонах, и его может не
  оказаться. Последнее — единственное, что можно проверить, и оно
  проверяется до игры (`SpeechService.status`). Молчать о
  недостающем голосе нельзя: игрок решит, что сломано приложение, а
  не что в системе нет языкового пакета.
- В `package:win32` 6.4 `Dispatcher.set` кладёт интерфейс в VARIANT **без**
  `AddRef`, а потом чистит вариант — то есть отпускает чужую ссылку. Любой
  COM-объект, передаваемый в `set`, нужно предварительно `addRef()`, иначе
  он умирает под ногами. Симптом — падение процесса по обращению к
  освобождённой памяти, а не исключение.
- Константы баланса живут только в `lib/domain/scoring/balance.dart` и помечаются
  `TODO(balance)`. Данные контента — `TODO(data)` со ссылкой на источник.
- Пуш и запуск сборок — через GitHub Desktop / вкладку Actions.

## Инварианты, которые легко нарушить

- `lib/domain/{srs,scoring,calibration,scheduler}` — чистый Dart без Flutter,
  Drift, сети и `dart:io`.
- Две базы: `content.db` (read-only, из ассетов, не мигрируется) и `user.db`
  (Drift с миграциями). Ни одна таблица не живёт в обеих.
- Меняешь схему контента — меняешь её **в двух местах сразу**: DDL в
  `tool/content_schema.dart` и таблицы в `lib/data/content/content_database.dart`,
  плюс версию `contentSchemaVersion` = `ContentDatabase.schemaVersion`.
  Расхождение ловит `test/data/content_schema_test.dart`.
- В метаданных контента нет и не должно быть метки времени: сборка обязана
  быть воспроизводимой байт-в-байт, иначе git засоряется пересборками.
- Источник правды по памяти — тройка FSRS `(difficulty, stability, lastReview)`.
  Яркость `lm` — производная величина, кеш для сортировки.
- Скоростной множитель — только для слов с яркостью ≥ 40 lm. На новом материале
  таймера нет.
- Концепт без файла озвучки не проходит валидацию: звук верного ответа — часть
  ядра игры, а не украшение.
- **В приложении нет сети.** Ни одного сетевого вызова, кроме Sentry, и тот
  молчит без DSN. Облако (M6), докачка паков (M8) и ночной вызов были
  написаны и удалены: они требовали хостинга и ключей, а игра обходится без
  них. Не возвращать `http`, `archive`, `supabase_flutter` и загрузчик паков
  без настоящего триггера — четвёртого языка изучения либо замены TTS на
  записи носителей. Код цел в истории git.
- Резервной копии у игрока нет, и это решение, а не пробел: переустановка
  лечится повторной калибровкой за пару минут. Значит, локальная БД — не
  кеш, а единственный экземпляр данных, и терять её нельзя ни при какой
  миграции.
- Ярус не запускается без вычитки. Машинная форма правила —
  `content/launch.yaml`: валидатор требует полноты только от запущенных
  ярусов, синтезатор озвучивает только их, приложение не даёт выбрать
  ярус выше. Урезание — единственным способом, `Tier.atMost(потолок)`:
  мест, где ярус назначается, пять, и написанное вручную сравнение рано
  или поздно забудут в шестом. Невычитанный ярус — это непрочитанный
  человеком текст, и синтез произнесёт его с той же готовностью, что и
  вычитанный: звук больше не сигнализирует о готовности яруса.
- Новые строки интерфейса идут во все шесть ARB сразу. Полноту проверяет
  `test/l10n_test.dart`: недостающий ключ молча откатывается к
  английскому, и заметить это невозможно.
- Новые пользовательские данные нужно добавить в двух местах: Drift-схема
  (+ миграция) и `bootstrapPersistence`.
- Любой новый контент — сразу `LocalizedText`; строки UI — во все ARB-файлы.
